# Era table: mechanisms and rulings by ship date

One row per mechanism or operator ruling that changed what a rubric dimension expects. A row is IN EFFECT for a run whose `window.end` (or spawn time when no window exists) is on or after `Shipped`. Grade the Before column for earlier runs and the After column for later ones. Under a mechanism, a violation it would have blocked is a hook regression raised against the orch, never an agent finding; a violation it cannot block stays the agent's. The dimension rows in `rubric.md` cite rows here by the Name column (`era: <name>`); `scripts/era.sh <window-end>` emits the in-effect / not-yet split that /resolve-run puts in the manifest as `era`.

Rows are append-only history: never edit a Before/After once a cohort graded against it; add a new row when the expectation moves again.
